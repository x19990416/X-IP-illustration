# 质量检查

## 必过项

- 尺寸符合用户要求；默认 16:9 横版。
- 纯白背景、黑色手绘线、克制的钴蓝强调。
- X 保留圆框眼镜、短发梢、蓝领巾和细线身体。
- X 承担核心动作，而非装饰。
- 一张图只表达一个主要关系。
- 留白充分，标注少且可读。
- 未出现“一毛半”或其他旧品牌标识。
- 不像 PPT、正式流程图、商业吉祥物或儿童插画。

## 失败处理

- **角色不像**：使用参考图局部编辑，不先改整体构图。
- **太像课件**：去掉标题、边框、网格和多余箭头，改成一个手绘场景。
- **太满**：只保留 X、一个核心对象和 3-5 个辅助元素。
- **文字错误**：局部替换；无法稳定修复时减少文字。
- **IP 只是装饰**：重新设计动词，让 X 完成拆解、连接、观察或讲解动作。
- **风格跑偏**：恢复纯白、黑线、钴蓝三色，移除阴影、渐变和写实背景。

高质量结果应当是：先看懂观点，再注意到 X；即使画面很简洁，也能感到角色正在认真解决问题。
