# 构图与原创隐喻

## 选择一种主结构

- **单一隐喻**：一个物理动作解释抽象观点。
- **前后对比**：左右呈现旧状态与新状态，X 完成中间转变。
- **三步过程**：最多三个阶段，X 推动主要流向。
- **局部系统**：只保留 3-5 个核心部件，X 操作关键部件。
- **拆解台**：X 把一个复杂对象拆成少量组成部分。
- **证据路径**：X 沿线索从问题走向结论。
- **小分镜**：2-4 格，每格一个动作，适合状态变化。

## 生成原创隐喻

1. 把观点改写成一个动词：拆、连、找、筛、搬、推、照亮、校准、回收。
2. 找一个朴素物件承载关系：积木、书页、抽屉、桥、放大镜、路标、绳结、筛网、拼图、秤、灯。
3. 让 X 亲自执行这个动作。
4. 删除与核心关系无关的物件和箭头。

避免直接复刻参考项目“小黑”的黑色怪物、怪机器和既有案例构图。这里只借鉴“角色参与观点表达”的方法，X 的视觉语言应保持蓝黑、理性、轻盈。

## 判断标准

读者应能在一秒内看出主要关系；角色动作应让关系更直观。如果需要大段文字才能解释图，构图还不够清楚。
