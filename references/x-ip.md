# X 角色规范

## 定位

X 是“知识火柴人”：好奇心驱动的知识探索者，用简单动作讲清复杂道理。它不是搞笑吉祥物，也不是某个真人的肖像。

## 不可丢失的识别点

- 白色圆头，黑色手绘轮廓。
- 圆框眼镜；眼睛清晰，不做夸张闪亮大眼。
- 头顶一小撮向上或侧上方翘起的短发。
- 黑色细线躯干与四肢，简化手脚。
- 钴蓝色小领巾，是最稳定的品牌色锚点。
- 表情温和、专注、略带思考感；不卖萌、不夸张。

生成前查看 `../assets/x-ip-reference.png`。图像参考高于文字想象；不要把 X 画成黑色实心怪物、机器人、儿童卡通人物或复杂穿搭的人类。

## 常用动作

- 托腮思考，问题气泡保持极简。
- 手持指示棒讲解一张简化图。
- 搬动、拆分或堆叠知识块。
- 拉起一条连接线，连接两个概念端点。
- 用放大镜观察证据、细节或异常。
- 抱着蓝色书本行走或递交知识。

动作可变化，但面部、眼镜、发梢和蓝领巾应保持一致。道具只选与观点有关的 1-2 个。

## 角色在画面中的职责

X 必须参与含义的形成。让 X 做“思考、解释、拆解、连接、观察、携带”中的一种核心行为，而不是站在角落摆姿势。

## 禁止

- 不要出现“一毛半”字样；角色名字是 `X`。
- 不要默认在成品图上写 `X`，除非用户要求标题、签名或品牌角标。
- 不要添加复杂服装、写实皮肤、肌肉、五指细节或二次元发型。
- 不要把眼镜、蓝领巾改成别的颜色或去掉。
- 不要把角色做成 3D、公仔、矢量企业吉祥物或儿童绘本风。
